===========================
Character Learning Activity
===========================

Transactional document for the character learning-design cycle and the
delivered activities used as practice arenas for character formation (ICLAD
Design Cycle, Bab 8 & Bab 10).

* **Learning-design cycle** -- one document unites the learning objective
  (RBT), the delivered activity (DOK), the planned evidence and success
  criteria (SOLO), and the feedback plan, tied to a character construct,
  arena, and method, and optionally to a Character Curriculum Map.
* **Alignment gate** -- the RBT-DOK-SOLO alignment-gate lines keep the
  objective, the activity, the planned evidence, the SOLO rubric, and the
  feedback plan aligned to the behavioral indicators being observed.
* **Full approval workflow** -- the activity is a document with the standard
  SSI transactional lifecycle Draft -> Confirm -> Approve -> Open -> Done /
  Cancel, with an automatically generated document number.
* **Neutral and configurable** -- the concrete objective, activity, and
  cognitive-demand levels are filled in per school by the user; nothing is
  hardcoded. The document deliberately links no discipline or counseling
  data (data governance boundary).


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school-character-learning
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *Character Learning Activity*
6.  Install the module
