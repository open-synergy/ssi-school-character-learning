=======================
Character Growth Report
=======================

Transactional document for the formative, narrative character growth
report of one student per academic term (ICLAD v2.3 Reporting, Bab 14 &
Growth Profile, Bab 21).

* **Growth profile per student** -- one document per student, academic
  year, and term gathers the homeroom teacher, the learning pathway
  (lite/core/full), the validating calibration session, and an overall
  growth narrative.
* **Per-construct growth lines** -- each line records, for one character
  construct, the achieved level from the configured scale, the growth
  narrative, the feedforward next step, and the linked character evidence,
  with a stored evidence count.
* **Full approval workflow** -- the report is a document with the standard
  SSI transactional lifecycle Draft -> Confirm -> Approve -> Open -> Done /
  Cancel, with an automatically generated document number.
* **Formative and non-labeling** -- the report is deliberately
  non-labeling, non-ranking, and carries no moral score. The narrative
  fields are free-text growth language with no fixed labels.
* **Data governance boundary** -- the report's only admissible evidence
  source is legitimate character evidence linked through the report lines;
  it holds no link to any discipline, counseling, psychological-test, or
  safeguarding record (ICLAD Bab 17 & Bab 14).


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school-character-learning
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *Character Growth Report*
6.  Install the module
