==========================================
Character Curriculum Map / Annual Syllabus
==========================================

Transactional planning document for character learning: the Character
Curriculum Map & Annual Syllabus (ICLAD Design Cycle, Lite/Core/Full
pathway).

* **Construct-to-arena mapping** -- for a given academic year, term, and
  grade/class, map each prioritized character construct (from the Character
  Framework master data) to a priority arena/program, a development method,
  a target mastery level, a delivery track, a learning outcome (Capaian
  Pembelajaran), and the behavioral indicators used to observe it.
* **Full approval workflow** -- the map is a document with the standard SSI
  transactional lifecycle Draft -> Confirm -> Approve -> Open -> Done /
  Cancel, with an automatically generated document number.
* **Neutral and configurable** -- the concrete mapping is configured per
  school by the user; no construct, arena, target level, or learning
  outcome is hardcoded. The document deliberately links no discipline or
  counseling data (data governance boundary).

Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school-character-learning
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *Character Curriculum Map / Annual Syllabus*
6.  Install the module
