# Create Character Construct

> **Module:** ssi_school_character
> **Model:** `school_character_construct`
> **Menu:** School > Configuration > Character Learning > Character Constructs
> **Actor:** Character Learning / User
> **State:** `—` → `draft`

## Pre-Condition

- **Access:** User is in group **Character Learning / User**.

## Flow

1. Open the **School > Configuration > Character Learning > Character Constructs** menu.
2. Click the **New** button. **(14.0: "Create")**
3. Fill in the required fields: **Name**, **Code**.
4. On the **Construct** tab, optionally select **Profile**, **Family**, **Scale**, and
   fill in **Definition** and **Boundary Statement**.
5. On the **Methods** tab, optionally add one or more **Methods**.
6. Click **Save**.

## Post-Condition

- A new Character Construct record is created and active.
