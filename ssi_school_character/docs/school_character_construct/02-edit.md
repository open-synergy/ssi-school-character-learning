# Edit Character Construct

> **Module:** ssi_school_character
> **Model:** `school_character_construct`
> **Menu:** School > Configuration > Character Learning > Character Constructs
> **Actor:** Character Learning / User
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record exists and is active.
- **Access:** User is in group **Character Learning / User**.

## Flow

1. Open the **School > Configuration > Character Learning > Character Constructs** menu.
2. Click the record to open it.
3. Click the **Edit** button.
4. Change the desired field(s), including the **Sub-constructs** tab lines.
5. Click **Save**.

## Post-Condition

- The record reflects the updated values.
