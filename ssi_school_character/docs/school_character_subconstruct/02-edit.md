# Edit Character Sub-construct

> **Module:** `ssi_school_character`\
> **Model:** `school_character_subconstruct`\
> **Menu:** School > Configuration > Character Learning > Character Sub-constructs\
> **Actor:** user in group `Character Sub-construct`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record exists and is active.
- **Access:** User is in group `Character Sub-construct`.

## Flow

1. Open the **School > Configuration > Character Learning > Character Sub-constructs**
   menu.
2. Click the record to open it.
3. Click the **Edit** button.
4. Change the desired field(s), e.g. **Definition**.
5. Click **Save**.

## Post-Condition

- The record reflects the updated values.
