# Edit Character Method

> **Module:** ssi_school_character
> **Model:** `school_character_method`
> **Menu:** School > Configuration > Character Learning > Character Methods
> **Actor:** Character Learning / User
> **Requires:** `01-create`

## Pre-Condition

- **Access:** User is in group **Character Learning / User**.

## Flow

1. Open the **School > Configuration > Character Learning > Character Methods** menu.
2. Find and open the record to edit.
3. Change the **Name**, **Code**, **Description**, or **Suitable For**.
4. Click **Save**.

## Post-Condition

- The record is updated with the new values.
