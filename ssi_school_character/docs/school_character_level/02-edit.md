# Edit Character Level

> **Module:** `ssi_school_character`\
> **Model:** `school_character_level`\
> **Menu:** School > Configuration > Character Learning > Character Levels\
> **Actor:** user in group `Character Level`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The record exists and is active.
- **Access:** User is in group `Character Level`.

## Flow

1. Open the **School > Configuration > Character Learning > Character Levels** menu.
2. Click the record to open it.
3. Click the **Edit** button.
4. Change the desired field(s), e.g. **Sequence** or **Description**.
5. Click **Save**.

## Post-Condition

- The record reflects the updated values.
