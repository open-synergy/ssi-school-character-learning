============================================================
Character Observation & Teacher Calibration - Operating Unit
============================================================

Operating Unit support for the SSI Character Observation & Teacher
Calibration (evidence) module. Adds operating unit access control to the
transactional models school_character_observation and
school_character_calibration, restricting each character observation
document and each teacher calibration session to one operating unit.


Work Instruction
================

* `Create Character Observation <docs/school_character_observation/index.html>`_
* `Create Character Teacher Calibration <docs/school_character_calibration/index.html>`_


Bug Tracker
===========

<https://github.com/open-synergy/ssi-school-character-learning/issues>`_. In case of
